# UmbrellaScreen

Rust + GTK4 screenshot overlay для Arch Linux / Hyprland.

```sh
sudo pacman -S --needed rust base-devel pkgconf gtk4 gtk4-layer-shell grim wl-clipboard
cargo build --locked
./target/debug/umbrellascreen
```

`SUPER + ]` в текущей конфигурации запускает этот debug-бинарник.

При запуске grim снимает мониторы параллельно с инициализацией GTK. Появляется затемнённый неподвижный кадр экрана. Выделите область мышью: она остаётся в исходном положении, сверху вниз выезжают инструменты, снизу вверх — действия. Перехода в отдельный редактор и увеличения выделенного фрагмента нет. Искусственных задержек запуска нет; остаётся время захвата и инициализации Wayland/GTK.

Выделение встроено в ту же GTK-поверхность, что и редактор. slurp больше не используется: его поверхность исчезает после выделения, а редактор нельзя встроить в чужой процесс. Используется Wayland layer-shell (слой overlay), а не обычные окна: поверхность сохраняется при переходе от выделения к редактированию.

- Перо, стрелка, прямоугольник, эллипс, текст; цвет и толщина.
- Ctrl+Z / Ctrl+Shift+Z: отмена / повтор.
- Ctrl+S: сохранить; Ctrl+C: копировать; Enter: обе операции.
- PNG сохраняется в `~/Pictures/screenshots/` с исходным разрешением выделенной области. Затемнение, рамка и панели не экспортируются.
- «Выделить заново» сбрасывает аннотации и позволяет выделить другую область того же кадра без перезапуска.
- «Фул скрин» выбирает весь кадр текущего монитора.
- Esc закрывает все поверхности без автосохранения.

Для текущей сборки gtk4-layer-shell извлечён из локального пакета Arch в `.native/` (каталог не включён в Git). На другой машине установите пакет `gtk4-layer-shell` перед сборкой.

Ограничения: выделение в пределах одного монитора; протягивание единой области через несколько мониторов пока не поддерживается. Содержимое экрана заморожено на момент запуска. Таймер и прежние CLI-режимы убраны из нового немедленного сценария. Инструменты могут перекрывать часть выделения, но в PNG они не попадают.

```sh
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
cargo fmt --all --check
```

Тестируются координаты масштабирования, Undo/Redo, PNG-экспорт с обрезкой до выделения и файловое сохранение. Дробный масштаб и интерактивные жесты требуют ручной проверки.

Панели компактные, центрированы сверху и снизу; кнопки используют собственные контурные Cairo-иконки. Подсказки появляются при наведении. Цвет и толщина переключаются нажатием на соответствующую иконку. Ctrl+S — сохранить, Ctrl+C — копировать, Enter — сохранить и скопировать. Строка состояния появляется при экспорте. Фон хранится в отдельной текстуре и загружается один раз. Renderer выбирается GTK, с учётом явно заданного GSK_RENDERER. При движении мыши обновляется только слой аннотаций и выделения.

Цвет теперь выбирается в выпадающей палитре, толщина — в меню 1/2/4/6/8/12/16 px. Текст: выберите инструмент T и нажмите внутри выделенной области; ввод открывается во всплывающем поле на оверлее, Enter подтверждает текст. После успешного сохранения и копирования через Enter или кнопку с галочкой приложение закрывает все поверхности. При ошибке остаётся открытым и показывает результат операций.

Глобальный запуск привязан к физической клавише `SUPER + code:35` (клавиша `]` / `ъ`). Сочетания редактора Ctrl+S/C/Z и Ctrl+Shift+Z используют аппаратные коды GDK Wayland и не зависят от активной раскладки. В поле текста эти команды не вызывают экспорт снимка.

Инструмент «Выбор» (курсор в начале верхней панели): нажмите на объект или текст, чтобы выделить его рамкой; перетащите для перемещения, Delete/Backspace удаляет. При перекрытии выбирается верхний объект по его прямоугольным границам. Перемещение и удаление поддерживают Undo/Redo. Рамка выделенного объекта не экспортируется. Enter вне текстового поля перехватывается до кнопок панели и запускает сохранение/копирование, даже если кнопка Undo ранее получила фокус.
